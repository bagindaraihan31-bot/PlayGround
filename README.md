# ZONA MATI

Survival shooter 2D top-down berbasis HTML, CSS, dan Canvas. Kota sudah jatuh: cari **3 bensin**, masuk ke gedung, kumpulkan senjata serta perbekalan, lalu capai **zona evakuasi** di utara sebelum malam tiba.

## Fitur

- 10 gedung yang bisa dimasuki, lengkap dengan interior dan kontainer loot.
- 5 senjata: pisau, pistol, shotgun, SMG, dan rifle.
- Sistem bertahan hidup: darah, stamina, rasa lapar, haus, makanan, minuman, dan obat.
- Musuh dengan AI flow-field, gelombang malam, dan zona evakuasi.
- Kontrol sentuh: dua joystick dinamis, tombol ambil/reload, dan tombol konsumsi.
- Kontrol desktop: keyboard + mouse.
- Tilt opsional lewat accelerometer, termasuk izin gerak iOS dan kalibrasi.
- Audio prosedural Web Audio tanpa aset eksternal.
- Peta mini, kompas objektif, skor, dan rekor tersimpan di localStorage.

## Menjalankan

Buka `index.html` lewat server statis, misalnya:

```bash
python3 -m http.server 3000
```

Lalu buka `http://localhost:3000`.

## Kontrol

**Phone / tablet**

- Stik kiri: bergerak. Dorong penuh untuk lari.
- Stik kanan: membidik dan menembak otomatis.
- `AMBIL`: loot kontainer di dekat pemain.
- `ISI`: reload.
- Tombol `Makan`, `Minum`, dan `Obat` di panel vital.
- `TILT`: aktifkan kontrol kemiringan (izin gerak diminta di iOS).

**Keyboard / mouse**

- `WASD`: bergerak.
- Mouse: bidik, klik kiri: tembak.
- `Shift`: lari.
- `E`: ambil loot, `R`: reload.
- `1`–`5`: ganti senjata.
- `F`: makan, `G`: minum, `Q`: obat.
- `Esc`: jeda.
